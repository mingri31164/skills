# 进行中

仍在开发中的技能。它们尚未准备发布——预计会有粗糙的边缘、破坏性变更和被放弃的实验。它们被排除在插件和顶层 README 之外，直到它们毕业到一个稳定的类别。

- **[review](./review/SKILL.md)** — 从两个并行轴线审查自某个固定点以来的变更：**标准**（diff 是否遵循仓库的编码标准？）和**规范**（diff 是否忠实实现了原始 issue/PRD？）。
- **[writing-beats](./writing-beats/SKILL.md)** — 将文章塑造成一段节拍的旅程，选择你自己的冒险风格。从原始材料中选择一个起始节拍，只写那个节拍，然后转向下一个，直到文章达到自然结尾。
- **[writing-fragments](./writing-fragments/SKILL.md)** — 深入质询会话，从用户那里挖掘碎片——异质的写作片段（断言、轶事、精辟句子、半成品想法）——并将它们追加到单个文档中，作为未来文章的原材料。
- **[writing-shape](./writing-shape/SKILL.md)** — 接受一份原始材料的 markdown 文件，通过对话会话将其塑造成文章——起草候选开场，一段一段地扩展文章，在每个步骤争论格式（列表、表格、标注块、引用）。
