# 生产力工具

通用的日常工作流工具，不限于代码。

- **[caveman](./caveman/SKILL.md)** — 超级压缩的沟通模式。通过删除填充词同时保持完整的技术准确性，将 token 使用量减少约 75%。
- **[grill-me](./grill-me/SKILL.md)** — 反复深入访谈你的计划或设计，直到决策树的每个分支都被解决。
- **[handoff](./handoff/SKILL.md)** — 将当前对话压缩成一份交接文档，以便另一个 Agent 可以继续工作。
- **[write-a-skill](./write-a-skill/SKILL.md)** — 创建具有正确结构、渐进式披露和捆绑资源的新技能。
