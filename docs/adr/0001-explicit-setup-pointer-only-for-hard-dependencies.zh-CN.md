# 仅对硬依赖项的显式 `/setup-matt-pocock-skills` 指针

工程技能依赖于 `/setup-matt-pocock-skills` 播种的每个仓库配置（Issue 追踪器、分类标签词汇表、领域文档布局）。某些技能无法有意义地运行而没有该配置——它们必须发布到特定 Issue 追踪器或应用特定标签字符串。其他仅使用它来锐化输出（词汇、ADR 意识），没有它则优雅降级。

我们将其分为**硬依赖**和**软依赖**技能：

- **硬依赖**（`to-issues`、`to-prd`、`triage`）——包含显式的一行：_"……应该已经提供给你——如果没有运行 `/setup-matt-pocock-skills`。"_ 没有映射，输出是错误的，而不只是模糊。
- **软依赖**（`diagnose`、`tdd`、`improve-codebase-architecture`、`zoom-out`）——仅用模糊散文提及"项目的领域词汇表"和"你触及区域的 ADR"。如果没有文档，技能仍然工作；输出只是不那么锐利。

这种分离使软依赖技能保持轻量级，并避免将设置指针加载到非关键的地方。
